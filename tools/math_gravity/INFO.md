# Math Gravity Calculator
## Name
Math Gravity Calculator
## Key
math_gravity
## Short description
Calculates gravitational force between two masses at a given distance.
## Long description
This tool calculates the gravitational force between two objects using Newton's law of universal gravitation.  It requires the mass of each object and the distance between their centers.
## Input parameters
- mass1: Mass of the first object in kilograms (required).
- mass2: Mass of the second object in kilograms (required).
- distance: Distance between the centers of the two objects in meters (required).
## Output
The gravitational force in Newtons, formatted to two decimal places.  Returns an error message if input is invalid.
