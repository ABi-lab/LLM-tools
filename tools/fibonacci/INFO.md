# Fibonacci Sequence Tool
## Name
Fibonacci Sequence Calculator
## Key
fibonacci
## Short description
Compute the Nth Fibonacci number.
## Long description
Returns the Nth term in the Fibonacci sequence:
- F(0) = 0  
- F(1) = 1  
- F(n) = F(n‑1) + F(n‑2) for n > 1  
This tool is useful for educational purposes, mathematical exercises, or algorithmic demonstrations.
## Input parameters
- **n** (number, required): The position in the Fibonacci sequence (non-negative integer).
## Output
The Nth Fibonacci number as an integer.
