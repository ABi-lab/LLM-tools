# Math Add Tool
## Name
Math Add Tool
## Key
math_add
## Short description
Returns the sum of two numbers.
## Long description
This tool takes two numeric inputs, `a` and `b`, and returns their arithmetic sum. It is useful for straightforward addition operations in calculations or prompts that require numeric aggregation.
## Input parameters
- **a**: The first number (required|optional, default: 0).\n- **b**: The second number (required|optional, default: 0).
## Output
An integer or floating‑point value representing the sum `a + b`.
