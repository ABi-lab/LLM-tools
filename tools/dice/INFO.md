# Dice

## Name
Dice

## Key
dice

## Short description
Rolls a random integer between 1 and 6 (inclusive).

## Long description
This tool generates a single roll of a six-sided die, returning a random integer from 1 to 6. It is useful for games, simulations, or any situation where a dice roll is needed. The result should always be an integer between 1 and 6.

## Input parameters
- numberSides: The number of sides on the dice (required|optional, default: 6)

## Output
An integer representing the dice roll.
