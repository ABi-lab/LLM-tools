# Fetch Web Page
## Name
Fetch Web Page
## Key
web_fetch_url
## Short description
Fetches a URL and returns its content as plain text with links preserved.
## Long description
Fetches the URL, strips HTML tags while preserving hyperlinks, and returns clean readable text. Use this to read web pages, documentation, or any online content.
## Input parameters
- **url** (string, required): URL to fetch
## Output
Plain text content with links in Markdown format [text](url).
